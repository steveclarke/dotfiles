# Reaction Rounds

The way taste gets into the prompt without the human needing design words.

## The page

- One review page per round, openable on a phone (a hosted artifact or local
  HTML page).
- Numbered cards. Each shows the example at phone and desktop width (still
  screenshots) or as a short clip (motion).
- Three buttons per card: **Yes / Sort of / No**, and an optional note. Taps
  save without a submit step.
- Terse answers are accepted as given ("3 yes, 7 no too corporate").

## The rounds

| Round | Spread | Purpose |
|---|---|---|
| 1 | 20-30 real, current examples across categories: the same kind of organization, neighbours, and the best-funded work of any kind | Find what pulls |
| 2 | 12-15 examples along one dial (quiet to strongly artistic, pale to bold) | Find where "too much" starts |
| 3 | Narrow set around the liked cluster | Confirm |
| Motion | Short clips of motion styles (easing, push-ins, hard cuts, scroll-driven scenes) | Name motion, which is harder to describe than stills |

Include the current version and earlier drafts as cards: dislikes of the
existing thing become named principles.

## After each round

Write the principles the reactions imply, strongest first, each with:

- the designer's term,
- the plain-words version,
- the examples that support it (yes and no).

The human confirms or corrects them. The principles file becomes the human's
own vocabulary, tied to their taste, and the prompt's "feel" section is built
from it.

## Rules

- The rounds agent does rounds only; the prompt is written with the human in
  the coordinating session.
- Screenshots of liked examples are kept beside the principles as evidence.
- Reactions to the current thing and to AI defaults count as much as likes.
